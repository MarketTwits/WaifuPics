# WaifuPics - Multiplatform Neko Images Application

## Project Overview

**WaifuPics** is a sophisticated Kotlin Multiplatform (KMP) application designed to provide users with random anime character (Neko) images and content. The application integrates with [NekosAPI v4](https://nekosapi.com/) to deliver high-quality Neko images, facts, quotes, wallpapers, and more across multiple platforms including Android, iOS, Desktop, and Web.

### Key Highlights
- **Cross-platform Support**: Single codebase targeting Android, iOS, Desktop (JVM), and Web (JS/WASM)
- **Modern Architecture**: Clean Architecture with modular design patterns
- **Declarative UI**: Jetpack Compose for all platforms
- **API Integration**: RESTful API client using Ktor 3.0
- **Local Caching**: Multiplatform persistence with KStore
- **Production Ready**: Complete CI/CD pipeline with automated deployments

## Architecture

### Architectural Pattern

WaifuPics follows a **Modular Clean Architecture** with strict unidirectional dependency flow:

```
┌─────────────────────────────────────────────┐
│    PLATFORM INSTANCES (instances/)          │
│  ┌────────┬──────────┬──────┬────────────┐ │
│  │Android │ Desktop  │ iOS  │    Web     │ │
│  └───┬────┴────┬─────┴───┬──┴─────┬──────┘ │
└──────┼─────────┼─────────┼────────┼─────────┘
       │         │         │        │
       ▼         ▼         ▼        ▼
┌─────────────────────────────────────────────┐
│       FEATURE MODULES (features/)           │
│ ┌─────────────────────────────────────────┐ │
│ │ Root  │ Random │ Gallery │ Settings    │ │
│ │ About │ Filter │ Report  │ Navigation  │ │
│ │ Cache Datasource                        │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
       │         │         │        │
       ▼         ▼         ▼        ▼
┌─────────────────────────────────────────────┐
│         CORE MODULES (core/)                │
│ ┌─────────────────────────────────────────┐ │
│ │ Theme  │ Async  │ Cache  │ Cloud       │ │
│ │ CoreUI │ Result │ Image  │ Comm        │ │
│ │ Paths  │                                │ │
│ └─────────────────────────────────────────┘ │
└─────────────────────────────────────────────┘
```

### Dependency Rules
1. **Instances** depend on **Features** and **Core**
2. **Features** depend on **Core** only
3. **Core** modules are self-contained (may depend on other Core modules)
4. No circular dependencies allowed
5. Platform-specific code isolated in source sets

#### Endpoints

##### GET `/images/random`
Fetches random images with optional filters.

**Query Parameters**:
- `rating` (string): Comma-separated age ratings (e.g., "safe,suggestive")
- `limit` (integer): Number of images to return (default: 1)

**Response**: List of `RandomImageItemCloud` objects

**Example Request**:
```kotlin
val images = nekoService.randomImage(
    ageRating = listOf("safe", "suggestive"),
    limit = 1
)
```

##### POST `/images/report`
Reports an inappropriate image.

**Query Parameters**:
- `id` (integer): Image ID to report

**Response**: Success/Error

**Example Request**:
```kotlin
nekoService.report(id = 12345)
```

### State Management

#### Communication Pattern
The app uses a custom `StateCommunication` pattern for reactive state management:

**Interface**: `StateCommunication` (modules/core/communication/)
```kotlin
interface StateCommunication {
    interface State<T> {
        fun state(): StateFlow<T>
    }

    interface Mutable<T> : State<T> {
        fun map(value: T)
    }

    abstract class Abstract<T>(initial: T) : Mutable<T> {
        private val _state = MutableStateFlow(initial)
        override fun state() = _state.asStateFlow()
        override fun map(value: T) { _state.value = value }
    }
}
```

**Usage Example**: `RandomImageCommunication` (modules/features/random/image/src/commonMain/kotlin/com/markettwits/waifupics/random/viewmodel/ImageViewModel.kt:98-101)

## Caching & Persistence

### KStore Integration

**Purpose**: Multiplatform key-value storage for favorites and settings

**Configuration**:

- **Web**: Browser Web Storage API (`kstore-storage`)

### Cache Architecture

#### ImageCacheRepository
Located at: modules/features/cache-datasource/src/commonMain/kotlin/com/markettwits/cache/image/ImageCacheRepository.kt:5-77

**Interface**:
```kotlin
interface ImageCacheRepository {
    fun observe(): Flow<List<ImageFavoriteCache>>
    suspend fun fetch(): List<ImageFavoriteCache>
    suspend fun addToFavorite(id, width, height, url, isProtected)
    suspend fun addOrDelete(id, width, height, url, isProtected)
    suspend fun deleteList(id: List<Int>, url: List<String>)
    suspend fun delete(id: Int)
    suspend fun delete(imageUrl: String)
}
```

**Implementation**: `ImageCacheRepository.Base` (line 33-77)
- **observe()**: Returns reactive Flow of favorites
- **fetch()**: One-time fetch of all favorites
- **addToFavorite()**: Adds image to favorites
- **addOrDelete()**: Toggles favorite state (line 56-68)
  - Checks if image exists with URL
  - Deletes if exists, adds if not
- **delete()**: Removes by ID or URL
- **deleteList()**: Batch deletion

#### ImagesCacheDataSource
Platform-specific data source abstraction:
- Wraps KStore operations
- Manages JSON serialization
- Handles file I/O

#### ImageFavoriteCache
Cached image data model:
```kotlin
data class ImageFavoriteCache(
    val id: Int,
    val width: Int,
    val height: Int,
    val url: String,
    val isProtected: Boolean
)
```

### Cache Flow

1. **Adding to Favorites**:
   ```
   User clicks heart button
   → ImageViewModel.onClickAddToFavorite()
   → RandomImageRepository.addToFavorite()
   → ImageCacheRepository.addOrDelete()
   → ImagesCacheDataSource.write()
   → KStore persists to storage
   ```

2. **Loading Favorites**:
   ```
   GalleryViewModel init
   → ImageCacheRepository.observe()
   → ImagesCacheDataSource.observeFavoriteImages()
   → KStore reads from storage
   → Flow emits List<ImageFavoriteCache>
   → UI updates with images
   ```

3. **Deleting Favorites**:
   ```
   User selects images and clicks delete
   → GalleryViewModel.onClickDeleteImages()
   → ImageCacheRepository.deleteList()
   → ImagesCacheDataSource.delete()
   → KStore removes from storage
   → Flow emits updated list
   ```

### Common Patterns

#### Creating a ViewModel

```kotlin
// 1. Define interface
interface MyViewModel : StateCommunication.State<MyState> {
    fun performAction()
}

// 2. Create implementation
class Base(
    private val repository: MyRepository
) : ViewModel(), MyViewModel {
    private val communication = MyCommunication.Base()

        }
    }

    override fun state() = communication.state()
}

interface MyCommunication : StateCommunication.Mutable<MyState>
class Base : StateCommunication.Abstract<MyState>(MyState.Initial), MyCommunication
```

## Common Issues & Solutions

### Build Issues

#### Issue: Gradle Sync Fails
**Solution**:
1. Clear Gradle cache: `./gradlew clean`
2. Invalidate caches in IDE
3. Delete `.gradle` and `.kotlin` directories
4. Sync again

#### Issue: Out of Memory Error
**Solution**: Increase heap size in `gradle.properties`:
```properties
org.gradle.jvmargs=-Xmx8g
```

#### Issue: Compose Compiler Error
**Solution**: Check `compose_stability_config.conf` and ensure Compose versions match across modules.

### Runtime Issues

#### Issue: CORS Error on Web
**Solution**: API calls use CORS proxy at `https://api.cors.lol/`. Ensure BASE_URL is correctly configured.

#### Issue: Images Not Loading
**Solution**:
1. Check network connectivity
2. Verify Ktor client configuration
3. Check Coil setup in `core-ui` module
4. Ensure image URLs are valid

#### Issue: Favorites Not Persisting
**Solution**:
1. Check KStore initialization
2. Verify platform-specific storage permissions
3. Check `ImagesCacheDataSource` implementation

### Platform-Specific Issues

#### Android

**Issue**: APK Installation Fails
**Solution**: Check `AndroidManifest.xml` permissions and `applicationId`.

**Issue**: Edge-to-Edge Not Working
**Solution**: Ensure `enableEdgeToEdgeWithSafeArea` is called and Material 3 theme is properly configured.

#### iOS

**Issue**: Framework Not Found
**Solution**:
1. Build framework: `./gradlew :modules:instances:ios:linkDebugFrameworkIosArm64`
2. Check Xcode framework search paths
3. Clean Xcode build folder

**Issue**: UIKit Integration Crash
**Solution**: Enable experimental UIKit in `gradle.properties`:
```properties
org.jetbrains.compose.experimental.uikit.enabled=true
```

#### Desktop

**Issue**: Window Doesn't Open
**Solution**: Check `Main.kt` exception handler and Koin initialization.

#### Web

**Issue**: WASM Not Loading
**Solution**:
1. Check browser WASM support
2. Ensure correct MIME types for WASM files
3. Use HTTPS for serving (required by some browsers)
